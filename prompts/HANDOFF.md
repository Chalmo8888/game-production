# 交接到其他设备或会话

在完成当前可安全结束的操作后保存检查点，不继续接新写入任务。不要覆盖/提交无关改动，不停止其他项目服务。

读取 Skill 的跨设备手册；更新 `.production/HANDOFF.md`：目标、当前阶段、最新提交与未提交差异、实际成果、已失败/未验证门禁、资产合同、版本和哈希、第一项下一工作及确切运行/验证命令、外部阻断、需同步但未进 Git 的授权资产。

STATE 标记真实交接/暂停状态。只有明确被授权的私有仓库和分支才自动同步；没有授权就准备经过检查的可移交文件清单或快照，不上传参考原件或密钥。

新 Agent 应能只靠仓库与此交接开始工作，不需要完整聊天记录。不要把阶段交接写成全项目最终完成。
