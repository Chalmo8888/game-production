# 通用启动 / 全流程无人值守

请读取当前项目的 `AGENTS.md` 与 `.agents/skills/game-production/SKILL.md`，按 v3 工作流执行。若 Skill 还在我提供的解压包中，先阅读 README，并在不覆盖现有文件的前提下安装到当前项目。

你负责的是按阶段组织的游戏生产工作，不限定任何软件、模型或设备；本会话有能力且获得授权的阶段都可由你完成。默认 mode=auto，不需要每个阶段等我确认。

先检查现有工程、Git 状态、文档、测试与实际构建，读取或保守初始化 `.production/`。以我的当前目标和项目中已有决定为准，锁定交付目标和验收标准；不要因为换 Agent 而重建项目、重做已验证的逆向、迁移技术栈、擅自缩小玩法或删除已有功能。

保留已取得的有效成果。按来源逐项决定合法复用、适配、独立替换或隔离，不将“参考成熟机制”变成从零编一个贫乏 Demo，也不把高风险源码改名或翻译后当可商用实现。不要声称新开会话自动构成严格洁净室。

按现状自动路由：S0 接管与来源 → 按需 S1 机制研究 → S2 实现和完整内容 ↔ S3 资产合同 → S4 正式资产制作与集成 → S5 综合验收和返工 → S6 本地候选与交接。阶段可交叉，QA 贯穿全程；已通过且证据仍有效的阶段不重复做。

当前设备有什么工具就实测什么工具。代码、美术、音频和 QA 不指定给某一家 Agent。有可靠独立审查能力时使用并保存真实记录；没有时执行严格自审并标注 self_review。缺一个工具先处理其他可推进任务，不伪造调用、图像生成、真人测试或独立 QA。

美术必须沿用或明确迁移当前资产契约。先用一个代表对象完成生成/制作、加工、导入、动作播放和逻辑回归，再批量生产。若我明确本轮不做美术，则交付可接续的资产合同，不把占位版称为最终成品。

每一轮都要实际检查：机制与内容覆盖、普通入口流程、失败/恢复、动画序列、资产引用、存档、性能、平台包及来源。测试数量、运行时间、代码行数、模式能启动、自动跳关和单张截图均不能替代完成标准。不能为过关删测试、降要求、挑成功种子或隐瞒未使用单位。

【无人值守规则】
现在开始调查并执行，直到达到当前目标可验证的交付要求，或遇到无法自行解决的真实外部阻断。只要执行环境允许、在授权和预算范围内、仍有有价值且可执行的工作，就持续开发、测试、检查、返工和扩展；完成一个功能、一个版本或一轮测试后自动推进下一项，不等待我回复“继续”。

同一方法连续失败三轮要诊断根因或换方案；一个任务受阻就记录并继续其他任务。不能空转、无限自调用或通过重复生成/重复测试刷工作时长。达到真实目标后结束，不无限增加无关功能。确实只剩外部授权、工具、真人或法务验证时给出候选和真实阻断，不擅自放行。

每个实质里程碑更新 `.production/STATE.json`、任务、门禁和 HANDOFF，并在合适时创建只含本任务改动的本地提交。会话/上下文/配额限制时保存精确恢复入口，不假装会话结束后仍在运行。

默认仅在当前项目内开发、测试和本地打包。未经明确预授权不 push、不公开部署、不收费、不修改线上或无关工程。已有权限以 PROJECT 中记录且来源于用户的授权为准。
