# 一次性完整生产：研究 → Base → 第一款游戏 → 交付

适用场景：你授权一个（或多个接力的）Agent 一次性完成研究、Base、Game 01 的策划、美术策划、开发、美术音频、QA 和本地发行候选。

