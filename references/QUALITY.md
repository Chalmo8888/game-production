# 质量门禁、证据与反自我放行

## 基本语义
GATES 是门禁状态唯一记录。状态：PASS、FAIL、UNVERIFIED、BLOCKED、NOT_APPLICABLE。PASS 要有实际证据；FAIL 是已观察缺陷；UNVERIFIED 是没验证；BLOCKED 是缺工具/权限/外部条件；NOT_APPLICABLE 仅因目标范围确实不适用且有范围依据。

不能以综合分数或通过测试数量掩盖单项重大失败。初始合同由用户目标和现有项目生成，落实到具体输入/结果/阈值后锁定；不得事后降低验收标准。确需修正错误标准，要保存理由、旧标准、新标准和来源，不以“更容易过”作为理由。

## 通用门禁
| ID | 检查对象 | 最少应有的证据 |
|---|---|---|
| G01 | 来源与复用 | 组件、资产、依赖清单；许可/来源记录；混合来源隔离结果 |
| G02 | 机制完整与准确 | 需求→实现→测试→差距；实际行为与数值单位；代理清单 |
| G03 | 内容与战术覆盖 | 范围内关卡/单位/模式清单，实际使用覆盖，变化的设计目的 |
| G04 | 资产生产与替换管线 | 小批量导入、损坏输入反例、动作/挂点检查、替换前后逻辑回归 |
| G05 | 正式表现与音频 UI | 真正加载的资源清单，连续动作序列，战斗视图与音频试听范围 |
| G06 | 正常输入流程与平衡 | 从正式入口通关/失败/重开记录，自动控制策略和种子分布，不隐藏失败 |
| G07 | 状态与存档 | 刷新、恢复、旧版本、损坏回退、暂停和关卡切换，适用时多游戏存档隔离 |
| G08 | 目标设备与性能 | 设备/浏览器/分辨率/渲染方式、持续时间、场景负载、帧时间与内存 |
| G09 | 包与宿主 | 最终包哈希、启动和相对路径、实际 SDK/manifest 版本、接口与泄漏检查 |
| G10 | 外部发行批准 | 项目要求的权利/品牌/法务/产品批准与公开发布授权，不由 Agent 擅自授予 |

G01 的工程来源审计通过不意味着 G10 已经获准。research/logic handoff 可缩小适用门禁，但不能把全项目的正式美术和发行要求偷偷删掉。

## 证据绑定
每个 PASS 至少记录：被测代码/资产快照、命令或操作路径、环境、观察结果、证据相对路径和 SHA-256、检查者与独立性。相关输入改变后重新运行受影响测试。文档提交改变不一定导致全部测试失效，但不能给旧构建的截图套新版本名。

证据文件存在只能证明文件在；摘要与哈希一致只能证明引用一致，不能证明游戏好玩或结论真实。Skill 辅助校验器不替代实际审查。

## 必须拆开的覆盖数据
游戏报告至少拆分：代码存在、单元行为验证、模式可启动、正常流程可通关、资产动画覆盖、不同种子成功/失败、目标设备实测。

不要说“50 关全过”，实际却只测 50 关能启动。自动玩家没有用过的武器/单位：独立机制测试可以通过，整关平衡仍未验证。至少用不同策略覆盖关键战术单位，而不是让一个最强阵容掩盖其他单位无效。

普通输入允许自动键鼠/手柄模拟，不允许直接加血、清敌、改胜利、绕波次。不具备完整通关能力时如实记录阻断及缺陷来源，不能为了证明可通关而偷偷改正常难度。

## 明确失败例子
- 隐形墙、逻辑软锁、环境判定错误、碰撞导致正常路线无法走通。
- 攻击状态、命中时刻、挂点、方向、脚点明显不一致。
- 核心敌人或 Boss 无有效动作、重要 UI 遮挡、正式版本静默使用未接受占位资源。
- 损坏存档破坏进度、跨游戏串存档、刷新后无法继续。
- 测试接口可在发行包修改状态，未知联网依赖或研究原件被打包。
- 修改测试数据、禁用校验或只挑成功种子作为全面通过。

具体“脚点不超过 2px”“60fps”等数字由项目世界比例和目标设备定义，不在全 Skill 中固定。

## QA 的独立性
取值：self_review、separate_context_same_environment、independent_reviewer。按实际记录；同一 Agent 切角色仍为 self_review。换软件不自动表示独立，独立 Agent 也不能当法律保证。

review 模式默认不改受审代码；失败项回任务池。auto 模式中的同一执行者可先审查、再切回实施修复、最后重新测试。缺少真人审查不应让其他工作停止，最终标记准确。

## 自动检查失败案例
校验器必须拿已知错误数据做反例，例如缺帧、错误资源 ID、错误锚点、损坏存档和不合法部署。不能只测试完美输入。资源替换不应改变规则时，可比较同一输入/种子下不含渲染细节的模拟状态摘要。

## 发行状态不混淆
STATE 记录的项目推进状态与发布批准分开。可以同时是“工程候选已打包”与“视觉/法务/真机待确认”；不能标题写“商业版已完成”，正文再说核心门禁全没过。
