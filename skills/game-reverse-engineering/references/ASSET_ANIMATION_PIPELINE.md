# 资源与动画管线规范（E5，P1/P2/P6）

## 1. 管线结构
```text
资产需求（清单 + 规格） → 生成或制作（原创/许可） → 自动加工 → 导入 → 校验（硬失败） → 运行时验证 → 接受/拒绝
```
每一步的输入和输出都有清单，资产使用稳定的语义 ID，不用文件路径当 ID。资源路径属于制作层，游戏通过 ID 引用。

## 2. 自动加工（从《勇者之路》提炼，有证据）
- **去背**：取四周边框颜色的中位数作为背景色，阈值内且与边缘连通的区域视为背景；白色主体改用灰底生成。
- **切帧**：给定期望帧数，按连通块切分；块数不符时依次放宽合并阈值，再尝试分水岭分割；**最终仍不符就失败退出，不能只打印 WARNING**（原项目只打印 WARNING 是已识别的缺陷）。
- **排序与打包**：按行列排序帧，生成图集和元数据（尺寸、锚点、帧数），并输出联系表预览供人工复核。
- **统一尺度**：同类单位按参考帧高度的中位数统一缩放，记录世界比例。
- **拆件**：把角色切成固定部件（数量不符就失败），记录每个部件的 pivot、挂接点、层级和是否镜像；自动测量部件朝向，防止像“两块小腿原图朝向相反，却按同一规则镜像”这样的错误。

## 3. 动画数据
- **逐帧**：clip（帧序列、每帧时长、循环方式、事件帧）。
- **拆件/骨骼**：骨骼树（pivot、attach、scale、flip、前后层）、姿势（各骨骼角度 + 混合时长）、关键帧招式序列；运行时做正向运动学和插值，贴地规则为取最低脚点。
- **状态映射**：逻辑状态 → 动画 clip 或姿势的映射表；切换渲染方案时只改映射层。
- **事件**：命中、发射、脚步、音效触发写在动画数据中，并与逻辑 tick 对照。

## 4. 校验（不符即失败）
- 清单中的每个 ID 都有文件；每个文件都被清单引用。
- 帧数、尺寸、锚点和挂点符合规格；动画引用的部件存在。
- 影响玩法的隐式契约（例如移动轨道、命中帧位置）有专门的断言。
- 文档或代码引用的规格文件必须存在。
- 发行或示例包中不含研究原件、原作资源或临时文件。

## 5. 替换与回退
- 支持分层覆盖：基础资产包 + 主题包覆盖。
- 开发模式下缺失资源时显式提示并使用标记明显的占位；验收用的资产包中，必需资源不能静默回退到占位。
- 替换前后在同一输入和种子下运行逻辑回归，单纯的美术替换不应改变规则结果。

## 6. 资产来源
测试资产使用原创内容（程序生成、AI 生成并记录工具条款、或自绘），记录来源和许可。不使用原作素材，也不使用刻意模仿原作造型的素材。可以把资产来源写进 REUSE.json（`source_kind: generated`），或者写进 Base 的 RIGHTS_LEDGER。
